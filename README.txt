SHAREDARU - APK banane ke 2 tareeke
1) GitHub: naya repo banao, is folder ki saari files upload karo -> Actions tab -> "Build APK" chalne do -> Artifacts se Sharedaru-APK download karo.
2) Android Studio: folder Open karo -> Build > Build APK(s).
Use: dono phone same Wi-Fi/Hotspot par. Receiver: "RECEIVE ON" dabaye, IP dikhega. Sender: files chuno, IP dalo, SEND.
Files milti hain: Downloads/Sharedaru
